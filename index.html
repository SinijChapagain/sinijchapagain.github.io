// research project

VIPT — Autonomous Vulnerability Intelligence & Penetration Testing

My MSc research prototype: an AI agent that runs structured, authorized web-application security assessments against lab targets, built to make AI-assisted testing repeatable, grounded, and safe. Written in Kotlin (~37k lines) with four genuine ML subsystems behind the reasoning.

Naïve Bayes vuln classifier

Maps lab objectives and HTTP responses to 30 vulnerability categories, with a Claude ensemble fallback when confidence is low.

Reinforcement learning

A UCB1 multi-armed bandit learns which payloads resolve each vulnerability type fastest, with a persisted Q-table that improves across runs.

Semantic retrieval

TF-IDF cosine-similarity search over a technique library ingested from public writeups, replacing brittle string matching.

LLM debate engine

Analysis and critique agents argue to a structured JSON verdict, reducing false positives before anything is reported as a finding.

Safety & scope enforcement

Hard scope guardrails and mandatory authorization constraints keep every run limited to explicitly approved lab targets.

Evaluation harness

Precision/recall measured against a fixed, hand-verified benchmark, plus pilot runs validated against PortSwigger and HTB-style lab machines.
